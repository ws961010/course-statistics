# 课程统计

这是一个可安装、可离线使用的每日课程统计网页应用，日期范围为 2026 年 8 月 1 日至 2036 年 8 月 31 日。

## 手机使用

首次使用时需要联网打开网页。首次完整打开后，页面会缓存到手机，之后断网也可以继续使用。

- iOS：使用 Safari 打开，点击“分享”→“添加到主屏幕”。
- Android：使用 Chrome 打开，点击浏览器菜单→“添加到主屏幕”或“安装应用”。
- 鸿蒙：使用华为浏览器打开，通过浏览器菜单添加到桌面；如果没有安装入口，可以收藏网页，离线缓存仍然有效。

## 数据保护

课程数据会同时写入 IndexedDB 和 localStorage。两份数据都属于当前浏览器，清理浏览器数据仍可能同时删除它们。

- 更换手机、清理浏览器或升级系统前，必须先导出 JSON。
- 建议每月至少导出一次 JSON，并重新导入一次确认备份有效。
- iOS 可保存到 iCloud Drive。
- Android 可保存到手机文件夹或个人云盘。
- 鸿蒙可保存到华为云空间或文件管理。
- 不同手机之间不会自动同步；迁移时使用 JSON 导出和导入。

## 隐私

所有课程记录只保存在使用者自己的浏览器中，不会上传到 GitHub。
